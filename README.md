# Облік витрат студента

Невеликий застосунок на Python і Streamlit для запису витрат, пошуку за назвою, групування за категоріями та перегляду місячних лімітів. Автор — Ворончак Василь, група П-31.

## Можливості

- три сторінки: перегляд витрат, додавання запису та інформація про автора;
- форма для додавання витрати й категорії;
- пошук, фільтр за категорією, статистика та діаграма;
- редагування й видалення витрат;
- SQLite з двома пов'язаними таблицями `categories` і `expenses`.
- сторінка автора з фотографією з `assets/author.jpg`.

Під час першого запуску створюються таблиці та додаються демонстраційні записи. Схема бази також збережена в `schema.sql`.

## Локальний запуск

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Підготовка до Streamlit Community Cloud

Проєкт містить залежності, README, `.gitignore` та SQL-схему. Щоб створити хмарний застосунок, завантаж файли проєкту в GitHub, відкрий `share.streamlit.io`, вибери репозиторій і головний файл `app.py`.

Публічне посилання на застосунок наразі відсутнє: розгортання ще не виконане.

Локальна SQLite-база зберігається у `expenses.db`; цей файл не додається до Git. У Community Cloud локальне файлове сховище не гарантує постійного збереження після перезапуску. Для постійного збереження записів під час хмарного використання треба під'єднати зовнішню базу даних.
